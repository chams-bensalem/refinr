## How to sign

Signing is done once, online, through the **CLA Assistant** service (<https://cla-assistant.io>):

1. Open a pull request. If you have not signed yet, the CLA Assistant bot comments on it with a link.
2. Follow the link, sign in with GitHub and accept this Agreement. The `license/cla` check of the pull request turns
   green and stays valid for your future pull requests.
3. Every author of the commits in a pull request must have signed: the e-mail address of your commits must be
   attached to your GitHub account.

Contributing on behalf of a company? Ask your employer first (section 5.1) and say so in the pull request.

If this Agreement is updated, the bot asks you to accept the new version on your next pull request.
